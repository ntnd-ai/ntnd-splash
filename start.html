Your first run

Start small.
Make something useful.

A clear first task teaches you more than a sprawling setup. Follow the work from the brief to the actual result.

Platform availability →
01
Install & choose a model

Give the workspace
a foundation.

When invited to a later cohort, use the build and installation instructions provided then. Connect a supported cloud provider with your own key, or choose a compatible model you have installed through Ollama.

Start with material appropriate for your model route. A cloud call sends the context included in it to the chosen provider.

Understand the setup ↗︎
02
Choose a role & a result

Ask for work
you can recognize.

Choose an agent role and give it a specific brief. “Research three approaches and prepare a sourced comparison” is easier to judge than “help with strategy.”

Add a few relevant documents and a method you have reviewed. Give the agent access to the material it needs.

A first brief

Compare three approaches to onboarding our first customers. Use these source notes. Deliver a one-page brief with sources, tradeoffs and open questions.

03
Start the work

Follow the run.
Meet the decisions.

Start a conversation or a configured workflow. Simply assigning a task does not by itself start an agent run.

When an action asks for permission, inspect the exact request. An ordinary approval applies once. A supported standing permission is a separate, explicit choice.

Practice a permission decision ↗︎
04
Inspect & respond

Open the result.
Decide if it is useful.

Open the actual delivered file. Check the claims, sources and fit with your brief. A run finishing does not prove the result is good.

Ask for corrections in the working conversation and share product feedback with the team. A richer connected review-and-learning cycle is still being built.

A useful future-alpha report

Tell us what happened.
Show us what mattered.

A useful feedback note
  • Intent: what you asked the agent to do.
  • Context: the model and relevant setup.
  • Result: what actually happened.
  • Correction: what you needed to change.
  • Boundary: a decision that surprised you.

Share only material you intend to make public in community channels. Use our contact form to arrange an appropriate channel for sensitive reports. Do not include the sensitive material in the form.
