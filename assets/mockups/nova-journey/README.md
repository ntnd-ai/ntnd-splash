# Nova journey — interactive concept

Standalone mockup at http://127.0.0.1:8038/assets/mockups/nova-journey/index.html. The built website tour is not connected to it. No build command is needed: the existing localhost server serves this assets folder directly.

The proposed experience is a working session: choose an article, research brief or team update; edit its subject and reader; choose sample sources; inspect a local/cloud boundary; approve or stop a bounded workflow; inspect the draft and its sources; request a concrete editorial revision; compare versions or download the sample.

All work is authored and simulated. No fetch calls, model calls, persistent storage, account changes or application mutations. The source snippets and results are fictional. Editorial direction is limited to three deliberate choices. The corresponding simulated review instruction appears with a short typing animation, makes its synthetic nature explicit, and is carried into the next authored draft. This is an experience proposal, not a claim that every interaction ships in the app today.
